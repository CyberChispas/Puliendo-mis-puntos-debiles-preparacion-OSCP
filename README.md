# 🛡️ Plan de Nivelación Técnica - Camino al OSCP | CyberChispas

Vengo de completar la certificación **eJPT** y de tener estudios en **Desarrollo de Aplicaciones Web**. Sin embargo, antes de realizar la inversión económica para adquirir el curso oficial y el examen del **OSCP**, considero imprescindible pulir ciertas bases técnicas. 

Este repositorio es mi bitácora para registrar la resolución de esos puntos débiles antes de dar el salto a la formación oficial de OffSec.

> ⚠️ **Nota de flexibilidad:** Este es el plan estructurado que he diseñado inicialmente. A medida que avance en los laboratorios y detecte nuevas necesidades técnicas, la ruta podrá sufrir modificaciones y adaptaciones.

---

## 🏎️ FASE 1: Plan de Nivelación Personal (Puliendo Puntos Débiles)

### 🗄️ Bloque 1: SQL & Seguridad Web (En Proceso)
- [ ] **W3Schools (SQL Tutorial):** Estudio de estructuras esenciales (`SELECT`, `WHERE`, `AND/OR`, `ORDER BY`, `UNION`, `INSERT`).
- [ ] **PortSwigger Web Security Academy:** Resolución de laboratorios prácticos de SQL Injection de forma manual modificando parámetros y empleando Burp Suite.
- [ ] **DVWA (Damn Vulnerable Web Application):** Despliegue de laboratorio local en Kali Linux para consolidar ataques SQLi manuales en niveles Low y Medium.

### 🐧 Bloque 2: Bash & PowerShell
- [ ] **OverTheWire (Bandit):** Superación de los niveles 0 al 25 para dominar la CLI bajo presión (`grep`, `awk`, `find`, `cut`, `sort`).
- [ ] **TryHackMe (Linux CLI & Bash Scripting):** Creación de scripts `.sh` (automatización de pings, bucles `for`, condicionales `if`).
- [ ] **TryHackMe / Microsoft Learn (PowerShell):** Sintaxis, cmdlets y tuberías (`|`) para listado de usuarios, servicios y procesos en entornos Windows.

### 🐍 Bloque 3: Python
- [ ] **W3Schools (Python Tutorial):** Sintaxis básica (variables, listas, diccionarios, bucles, funciones e imports).
- [ ] **Libro "Black Hat Python":** Desarrollo línea a línea en Kali Linux de herramientas de red personalizadas (sustituto de Netcat, sockets TCP/UDP y manipulación de peticiones web).

### 🚀 Bloque 4: Integración Práctica (El Puente)
- [ ] **TryHackMe (Offensive Pentesting Path):** Aplicación integrada de SQL, Bash y Python para comprometer máquinas completas guiadas paso a paso.

### 🏔️ Bloque 5: Auditoría Manual (Lista TJnull)
- [ ] **Hack The Box / Proving Grounds Practice:** Resolución intensiva de **35-40 máquinas** seleccionadas de la **Lista TJnull**. 
  - *Regla personal:* Mínimo 2 horas de enumeración manual exhaustiva antes de consultar cualquier guía externa.

## 🎓 FASE 2: Preparación Directa y Certificación Oficial (OffSec)
*Este bloque comenzará una vez adquirida la suscripción oficial a Offensive Security:*

- [ ] **Curso Oficial OffSec PEN-200:** Completar el 80% del contenido teórico y laboratorios del temario para asegurar los 10 puntos adicionales del examen.
- [ ] **PEN-200 Challenge Labs:** Superación de los entornos internos de simulación de examen de OffSec.
- [ ] **Examen Oficial OSCP** ➔ *Objetivo Final*
